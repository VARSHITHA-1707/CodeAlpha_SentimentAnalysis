# Data Analytics Internship - Task 4: Sentiment Analysis

## 📌 Project Overview
This project is part of the CodeAlpha Data Analytics Internship. The goal is to analyze text data using NLP techniques and lexicons to classify sentiments (Positive, Neutral, Negative) and understand public/text trends.

## 🛠️ Tools & Libraries Used
* **Language:** Python 3.x
* **Environment:** Google Colab
* **Libraries:** `pandas`, `nltk` (VADER Lexicon), `matplotlib`, `seaborn

## 📊 Key Results
* Processed book titles to evaluate emotional tone and polarity.
* Visualized sentiment distribution across the scraped dataset using count plots.
